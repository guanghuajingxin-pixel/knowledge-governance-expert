知识应用

应用是治理的基础。三端共用统一检索服务（Dify 承载），每次问答都带引用、可反馈——问答日志是治理最重要的数据来源。

🤖 Dify 智能体

  • 设备智能体 / 新员工导师 / 制度助手 等 5 个在线
  • 路由：先选库，再决定 rerank/多跳（审计留痕）已配置
  • 问答日志 → 回流治理（命中率/无结果/反馈）开启

✨ 千问办公

  • 已注册知识域：品质检验 / 制度标准 / 商品方案3 个
  • 仅注册质检达标库（健康度<60 不注册）门禁联动
  • 「无结果」事件 → 写入缺口看板开启

👤 人类门户

  • 语义检索 + 权限内预览开启
  • 一键跳转钉钉原文阅读/编辑开启
  • 纠错入口与智能体反馈同轨开启
