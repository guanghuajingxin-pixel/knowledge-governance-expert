# UI / UED 设计规范

> 本规范对所有 Web 界面的新增与修改**强制生效**（见 AGENTS.md）。目标：减少用户操作疲劳、保持全局一致性、杜绝随意设计。技术基线：Vue 3 `<script setup lang="ts">` + Element Plus 2.x + TS strict。全站中文界面。

## 1. 布局稳定（防跳动）

- **控件行的构成在交互前后必须保持几何稳定**：切换选项/状态时，禁止出现或消失占行控件。需要"不同模式不同输入"时，用等宽占位（如只读禁用输入框展示固定值）替代 `v-if` 移除控件。
- 状态类文案（已连接/检测中/未连接等）长度多变，容器必须设 `min-width` + `white-space: nowrap`，溢出用省略号。
- 数字/计数变化区域使用 `font-variant-numeric: tabular-nums` 或固定宽度，避免列宽抖动。
- 异步加载区域保留骨架或 `v-loading`，加载完成高度突变超过一行的场景需预估占位。

## 2. 说明文案（信息分层）

- **辅助说明默认不常驻占行**：用 `el-tooltip`（hover 展示）挂在 ? 图标（`QuestionFilled`，`cursor: help`）或触发控件本身上。? 角标**绝对定位于所属对象的右上角**（`position:absolute; top:-7px; right:-9px`，14px），不与其平行占行内主轴位置——平行摆放会抢占视觉焦点（参考 `.engine-wrap` 模式）。
- 常驻行内 hint（`.field-hint`，12px `#909399`）仅用于**不可 发现的必要约束**（如"留空表示不修改已保存的 Key"），单行、置于控件正下方 4px。
- 可推导信息（版本号、输出格式、状态详情）一律进 tooltip，不在行内铺陈。
- tooltip 内容为一句话，动词开头或名词短语，不加句号。

## 3. 反馈分层

| 场景 | 载体 | 规则 |
|------|------|------|
| 操作瞬时结果（保存/删除/复制成功） | `ElMessage`（顶部悬浮） | 默认 3s 自动消失；成功 `success`、失败 `error`、警示 `warning` |
| 需要用户驻留查看的结果（连通性报告、校验详情） | `el-alert`（块级，可关闭） | 跟随其归属的表单项，不横跨整页 |
| 长驻状态（连接状态、生效中） | `el-tag`（plain + 圆点 `.dot`） | 固定最小宽度，颜色语义见 §6；轻量场景（按钮连通性）可改为**对象右上角圆点角标**（`.conn-dot`，10px 白描边，绿=正常/红=失败，hover 展示详情），不新增行内元素 |
| 破坏性操作确认 | `ElMessageBox.confirm` | 文案包含对象名与后果 |

- 禁止用 alert 承载瞬时成功消息，禁止用 Message 承载长文本。

## 4. 按钮与动作

- 同一区域**主按钮唯一**（`type="primary"` 实心）；次要动作用 `plain` 或默认；破坏性用 `type="danger"` + 二次确认；查询/测试类常用 `plain primary`。
- 关键动作（保存）与前置校验动作（测试连通性）同行排列，校验动作在主按钮之前。
- 文案动词开头、明确对象：`下载原文` ✔ / `原文` ✘；不超过 6 字优先。
- 列表行内动作 ≤3 个外显，其余收进「更多」（`…` 触发下拉），删除归入更多。
- 纯图标按钮必须有 tooltip 说明。

## 5. 表单与控件尺寸

- 控件统一 `default` 尺寸（表格内 `small`）；间距 8px 栅格（4/8/12/16/24）。
- 输入框宽度按内容语义固定：URL/路径类 280px，短码/数字 120–160px，搜索框 ≥240px；**不用 flex 自适应宽度**（防抖动）。
- 相关控件同行用 `display:flex; gap:8px; align-items:center`（`.field-row` 模式），说明除外。
- 开关类控件：只展示当前状态文案，控件与文案同一行，提供可访问名称。

## 6. 颜色语义（沿用全局 Token）

| 语义 | Token | 用途 |
|------|-------|------|
| 主操作/链接/选中 | `--el-color-primary` `#409EFF` | 唯一主按钮、链接、激活态 |
| 成功/完成 | `--el-color-success` `#67c23a` | COMPLETED、连接成功 |
| 处理中/警示 | `--el-color-warning` `#e6a23c` | PARSING/INDEXING、待确认 |
| 危险/失败 | `--el-color-danger` `#f56c6c` | 删除、FAILED、待更正 |
| 次要信息 | `--el-color-info` `#909399` | 辅助文字、未激活 |

- 同类状态全站同色同形（圆点 + plain tag）；禁止自造颜色。

## 7. 表格与弹窗

遵循 AGENTS.md「表格与弹窗布局要求」，要点：内容列 `min-width` 占据剩余空间、控件列固定 `width`；长名称 `show-overflow-tooltip`；弹窗内核对列宽总和；空态用 `el-empty`。

## 8. 空态、加载与边界

- 空列表必须 `el-empty`（description 说明下一步动作），不留白板。
- 首次进入的可配置功能，空态即引导（"尚无 X，点击「新增」添加；未配置时 Y 兜底"）。
- 边界提示具体化：错误文案含原因与出路（"未配置 MinerU API Key：请在模型配置页填写并保存"），禁止裸 "失败"。

## 9. 交付自检清单

改版/新增界面前逐项核对：

- [ ] 切换任意选项/状态，行高与行宽无跳动
- [ ] 说明文案已收敛为 tooltip 或单行 hint
- [ ] 主按钮唯一、动作文案动词开头
- [ ] 反馈载体符合 §3 分层
- [ ] 空态/加载/错误三态齐全且文案具体
- [ ] 状态色与 §6 语义一致
