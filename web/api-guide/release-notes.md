# 发版记录

> 本页由发布流程维护：每次发布新版本到服务端前，先把版本变更信息更新到本页，随版本一同上线；
> 发布后在「知识治理专家运营群」同步通知。版本倒序排列。

## 2026-10-20 · `9165e98`（问答检索提速 + sidecar 热重载）

- **检索提速**：多知识库并行检索（库间并行 + 每库内向量/关键词双路并行），统一检索与 RAG 问答的召回延迟显著下降；检索内核启动预热真正生效（分词词典加载约 5 秒不再由首次检索承担）
- **智能体配置热更新**：模型配置/智能体配置保存后问答服务即时生效（免重启）；问答页展示实际运行的模型名，与配置热更新保持一致
- **问答稳定性**：问答服务瞬时未就绪自动重试；服务不可用时提示语改为可理解的中文（不再暴露内部组件名）
- **模型配置防错加固**：智能体配置引用已删除的模型时自动回退系统默认模型，修复模型名与问答服务端点不匹配导致的问答 400 报错
- **修复问答页复制失败**：HTTP 环境访问时「复制」按钮不可用，改用带降级的统一剪贴板方案（fe66e54）

## 2026-10-19 · `8c820b3`（hotfix：AI 表格导出 + 重试死循环）

- **钉钉 AI 表格（.able）支持**：生产服务器安装钉钉官方 dws CLI（登录态持久化，授权账号操作），同步链路可自动导出 AI 表格为 Excel 再解析；在线文档（.adoc）与在线表格（.axls）同链路一并打通
- **修复重试死循环**：任务重试后仍报旧错误——批处理孤儿收尾误杀刚认领的重试任务（回放认领前的旧失败状态）；现在只收「文档终态出现在认领之后」的组合，重试任务可正常重新下载上传

## 2026-10-19 · `4d58008`（自动同步改事件驱动）

- **自动同步改事件驱动（架构升级）**：取消 cron 定时编目，改为订阅钉钉知识库变更事件实时触发——文档在钉钉侧保存/修改后自动进入同步队列（按源 30s 去抖合并），同步列表不再展示定时配置；XXL-Job 仅保留批处理分批消费
- **流式编目**：整库导入边遍历边落库，首批「待同步」文档秒级可见，不必等全树遍历完；指定文档模式免整树遍历，选几篇查几篇
- **解析引擎（新页面）**：知识采集新增「解析引擎」页——自定义解析测试台（上传/队列/结果预览）与 MinerU WebUI 双页签；文档库支持质量档位（speed/balanced/quality）与 OCR 策略库级配置
- **重新分段**：文档索引设置保存后用已落盘解析缓存直接重建分段（不重走 MinerU 解析），秒级生效
- **知识中心批量删除**：按来源/标签/搜索结果批量删除文档（单批 ≤100），整删 MinIO 存储并级联取消排队任务
- **分段增强**：多字符分隔符（如 `###`）按结构切段、换行/段落边界语义对齐 Dify，存量配置零迁移兼容
- **稳定性修复**：启动连接池预热空转（全站首次点击慢）、钉钉 Stream 任务关不干净（热重载后旧进程占满数据库连接）、数据库抖动误判凭证失效（登录后闪退）、Wiki 任务跨事件循环丢失、MinerU 云任务重启后自愈、钉钉 API 限流断连自动退避重试
- **工程规范**：新增架构设计/后端编码/测试三份规范文档，统一「?」暗提示组件 HelpTip

## 2026-10-16 · 角色与账号管理

- **门户角色管理（新功能）**：系统 4 角色之外支持自定义角色（菜单白名单控制可见性），角色列表/新建/编辑/删除全在门户「系统管理」；local 模式管本地账号，keycloak 模式同步身份中心 client role（迁移 0062）
- **门户账号管理增强**：local 模式下直接管理本地账号（建号/停用/角色分配/重置密码），双认证模式统一入口
- **本地开发一键启动**：`scripts/start-dev.sh local|keycloak`（认证策略启动时确定，经 SSH 隧道复用生产身份中心）
- **品牌视觉统一**：主色切换为品牌蓝 `#2B6BFF`
- 修复：SyncRun.started_at 应用侧本地默认（sqlite 测试与生产 PG 同基准）

## 2026-10-15 · `0060`（时间统一东 8 区）

- **系统时间统一北京时间**：此前容器与数据库均按 UTC 记录时间，界面上的同步/文档/任务时间比北京时间早 8 小时；本次全部业务容器与 PostgreSQL 统一注入东 8 区，存量数据一次性对齐（迁移 0060）
- **同步修复**：faq-service 认证模式被 compose 单方面强制为 keycloak（与全站 local 现状不一致），已改回与 kb-api 同口径由配置文件控制
- **Wiki 知识库（新功能）**：Karpathy LLM Wiki 模式——从文档库一键生成 Wiki 页面，支持生成任务追踪与中断恢复，Wiki 库独立页面视图（此功能随本次一同上线）

## 2026-10-15 · `4f8b353`（hotfix：批处理更新文档跨事件循环修复）

- **单次导入走同步队列**：添加知识「单次导入」改为经 XXL-Job 分批下载解析，全部完成后源自动停用（不随钉钉源文件更新），进度可在「知识采集 → 同步队列」查看

- **hotfix**：修复批处理任务在执行器线程复用主事件循环数据库连接池导致的跨 loop 崩溃——`mineru_saas` 读取 SaaS 配置与同步引擎等待解析两处改用独立短命引擎（更新/新建文档此前均会失败）
