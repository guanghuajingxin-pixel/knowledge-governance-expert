# 发版记录

> 本页由发布流程维护：每次发布新版本到服务端前，先把版本变更信息更新到本页，随版本一同上线；
> 发布后在「知识治理专家运营群」同步通知。版本倒序排列。

## 2026-10-16 · 角色与账号管理

- **门户角色管理（新功能）**：系统 4 角色之外支持自定义角色（菜单白名单控制可见性），角色列表/新建/编辑/删除全在门户「系统管理」；local 模式管本地账号，keycloak 模式同步身份中心 client role（迁移 0062）
- **门户账号管理增强**：local 模式下直接管理本地账号（建号/停用/角色分配/重置密码），双认证模式统一入口
- **本地开发一键启动**：`scripts/start-dev.sh local|keycloak`（认证策略启动时确定，经 SSH 隧道复用生产身份中心）
- **品牌视觉统一**：主色切换为品牌蓝 `#2B6BFF`
- 修复：SyncRun.started_at 应用侧本地默认（sqlite 测试与生产 PG 同基准）

## 2026-10-15 · `0060`（时间统一东 8 区）

- **系统时间统一北京时间**：此前容器与数据库均按 UTC 记录时间，界面上的同步/文档/任务时间比北京时间早 8 小时；本次全部业务容器与 PostgreSQL 统一注入东 8 区，存量数据一次性对齐（迁移 0060）
- **同步修复**：faq-service 认证模式被 compose 单方面强制为 keycloak（与全站 local 现状不一致），已改回与 kb-api 同口径由配置文件控制
- **Wiki 知识库（新功能）**：Karpathy LLM Wiki 模式——从文档库一键生成 Wiki 页面，支持生成任务追踪与中断恢复，Wiki 库独立页面视图（此功能随本次一同上线）

## 2026-10-15 · `4f8b353`（hotfix：批处理更新文档跨事件循环修复）

- **单次导入走同步队列**：添加知识「单次导入」改为经 XXL-Job 分批下载解析，全部完成后源自动停用（不随钉钉源文件更新），进度可在「知识采集 → 同步队列」查看
- **编辑静默期**：钉钉文档编辑中的变更（静默不足 10 分钟）不建同步任务，编辑结束后由下轮调度自动接管；手动同步不受限
- **hotfix**：修复批处理任务在执行器线程复用主事件循环数据库连接池导致的跨 loop 崩溃——`mineru_saas` 读取 SaaS 配置与同步引擎等待解析两处改用独立短命引擎（更新/新建文档此前均会失败）

## 2026-10-14 · `080bc26`
